# 透明度档位与提示词

透明度是用户指定的单层视觉目标，不是实测透光率。1到5按所选对照图从最透到最不透；第四档沿用图上的“半透明”。

ComfyUI新增 FabricTransparencyControls（透明度档位），放在共用Faithfulness后：原始实拍与规则进入它，它把带角色说明的原图/辅助图和提示词交给各场景。示意图预览单独输出。text只发送档位文字，image只附选中一列，不上传整个五列图。无图text模式的预览为空白占位。

该五列图标定区域为0,0.235,1,0.845，每列内侧留边，移除文字、箭头、脚部和相邻档位。换对照图需重新标定，不能盲套。自动裁切只作用于透明度示意，真实面料保持完整画幅，不模糊、不做自动特写。

独立配方的material_controls字段：transparency_level为1–5，reference_mode为text/image，chart_file为本机对照图路径，chart_region为归一化左上右下坐标。参考图编号由实际输入顺序生成；其他style图独立标注。

提示词分为：逐图材料事实、共享真实性规则、透明度目标、开放式可穿着设计方向、人物摄影和单张构图。叠层不是一律加深，厚度未知就留空；半透明不等同于白色罩裙的材质。整体图决定综合色和重复分布，近景解释组织，不主导成衣尺度。保留素色不透内搭与包头包跟鞋。

本轮只有拆分、文案修改与离线测试，没有新生成结果。控制不能保证模型遵循，需后续单张对照。公开仓库不附私人对照图或裁图。
