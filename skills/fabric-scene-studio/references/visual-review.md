# Visual review

Inspect the actual model, quality, image list and assembled prompt. Seeing a style image in the agent conversation does not mean it was sent to the image API. Do not infer the original model, settings or batch success rate from a finished collage.

Separate material fidelity, garment construction, model expression and photography. Real fabric photos determine color, weave, translucency and drape; style references guide presentation. Explicitly label each role and replace an old all-images-are-fabric instruction before appending style images.

Hold the outfit and material fixed when comparing quality. Add a style reference as a separate comparison, then revise art direction. This is not automatic authorization for multiple paid calls. Higher quality does not ensure textile topology or calibrated color. Avoid fixing every design to one hairstyle, pose or background.

Do not invent GSM, composition or millimeter scales. Check linings separately from sheer cloth. Cache replay is not repeat-generation stability. Verify current parameters in official image documentation when needed: https://developers.openai.com/api/docs/guides/image-generation .
